# Alex Morgan — portfolio

An original responsive portfolio inspired by the visual rhythm of aayushbharti.in. Built with Next.js App Router, React, TypeScript, Tailwind CSS v4, and GSAP ScrollTrigger.

Run npm install and npm run dev, then open http://localhost:3000. Production verification: npm run build. Type check: npm run typecheck.

Customize the identity, projects, contact address, social links, and notes in app/page.tsx. Global design tokens and responsive styles live in app/globals.css. Local photography lives in public/images.

Interactions include mobile navigation, technology filters, case-study dialogs, expandable notes, email copying, hover states, and scroll reveals. Motion respects prefers-reduced-motion.

See docs/reference-review.md for the reference observations and design rationale. The identity and projects are illustrative demo content. Photography: Unsplash.
